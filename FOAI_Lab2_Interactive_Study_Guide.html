🎖️ Colonel West: The Criminal Problem (`criminal.pl`)

The famous First-Order Logic to Horn clause inference proof from Russell & Norvig.

FOL → HORN CLAUSE TRANSLATION

English Sentences to Prolog Code

▼
criminal.pl
/* Facts */
american(west).
enemy(nono, america).
missile(m1).
owns(nono, m1).

/* Rules */
weapon(X) :- missile(X).
hostile(X) :- enemy(X, america).
sells(west, X, nono) :- missile(X), owns(nono, X).

criminal(X) :- 
    american(X), 
    weapon(Y), 
    sells(X, Y, Z), 
    hostile(Z).
How to Trace Inference in SWI-Prolog:
Type ?- trace. then ?- criminal(west).
Prolog walks through the 4 ports:
1. Call: criminal(west)
2. Call: american(west) → Exit: true
3. Call: weapon(Y) → matches missile(m1) → Exit: Y = m1
4. Call: sells(west, m1, Z) → checks owns(nono, m1) → Exit: Z = nono
5. Call: hostile(nono) → checks enemy(nono, america) → Exit: true
6. Exit: criminal(west) → true.

🧠 Top Viva Questions & Exact Answers

THEORY & VIVA

Answers to Impress the Professor

▼
Q1. What programming paradigm does Prolog use?

Declarative programming. You declare truths and relationships (Facts and Rules) rather than step-by-step algorithms.

Q2. What inference method and search strategy does Prolog employ?

Backward chaining with SLD-resolution and unification, exploring choice points using Depth-First Search (DFS) with automatic backtracking.

Q3. What is a Horn clause?

A logical clause with at most one positive literal. In Prolog: Head :- Body.

Q4. What is Closed World Assumption (CWA) and Negation as Failure (NAF)?

Prolog assumes everything not stated or provable from its database is false. Written as \+ Goal.
